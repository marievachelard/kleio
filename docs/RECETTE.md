# Test sur un iPhone

À faire une fois par téléphone.

1. Ouvre https://kleio.marievachelard.workers.dev dans Safari.
2. Touche le bouton Partager, puis « Sur l'écran d'accueil ».
3. Ouvre Kleio depuis son icône, puis touche « Réglages » en bas du calendrier.
4. Touche « Activer les notifications » et accepte la fenêtre d'iPhone.
5. Touche « Envoyer une notification de test » : elle doit arriver sur l'écran.
6. Touche la notification : Kleio s'ouvre sur les réglages.
7. Le lendemain, la vraie notification arrive à 08:30. Touche-la : le détail du jour s'ouvre, avec la source en bas.
